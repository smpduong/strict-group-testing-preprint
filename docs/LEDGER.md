# Claim ledger (draft, 2026-10-19)

Scope of the evidence: only the 2014 paper (DSW), Grankvist 2017, and this repository were examined. No citation index or web source was consulted; "Strongest primary source" means the strongest *among those*, plus the works they cite. "Potentially new" means "not found in the sources examined", not "verified new".

Abbreviations. DSW = P. Damaschke, A. Sheikh Muhammad, G. Wiener, "Strict group testing and the set basis problem", J. Combin. Theory Ser. A 126 (2014) 70-91 (conference version COCOON 2013, LNCS 7936, 446-457). Grankvist = D. Grankvist, "Searching for Search Strategies: Solutions to Strict Group Testing Problem Instances", MSc thesis, Chalmers/Univ. of Gothenburg, May 2017 (supervisor P. Damaschke). HH = S. H. Huang, F. K. Hwang, SIAM J. Discrete Math. 14 (2001) 540-548.

Status update 2026-10-19 (reviewer-driven revision). Statements below that predate it are corrected in place or marked "historical". The precise model, definitions (t, f, signatures, W, p(W), m_W, Lemmas A and B, g(9)) and a dependency chain are in `docs/note-draft.md`, Sections 1 and 6.

Common model for the t(n,2,2) rows: strict group testing; n items; at most d=2 are positive; the searcher must output the positive set exactly if it has size <= 2 and report "more than 2" otherwise; tests are pooled (positive iff the pool contains a positive item); at most s=2 stages, tests within a stage are fixed jointly (nonadaptive), the second stage may depend on the stage-1 outcome; deterministic; pools of arbitrary size and overlap; t(n,d,s) = minimum over strategies of the worst-case total number of tests (both stages).

It follows in two lines from DSW Cor. 5, so a more general literature may well contain it. | Potentially new as a stated tool (limited check); small mathematical content.
